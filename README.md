# DANDU — Maroquinerie Artisanale du Cameroun

Site vitrine et boutique en ligne de **DANDU**, maison de maroquinerie artisanale
fondée en 2017 à Yaoundé (Cameroun) par Daniel & Urweiller.

## Caractéristiques
- Site **monopage** autonome (`index.html`) — bilingue **🇫🇷 FR / 🇬🇧 EN**
- Catalogue : **Sac Zona**, **Claquettes Yao Boy**, **Sac Kléopé**
- Hero vidéo + galeries produits, panier persistant
- Commande directe via **WhatsApp**
- Médias (photos, vidéo) dans le dossier [`assets/`](assets/)

## Mise en ligne
Publié avec **GitHub Pages** depuis la branche `main` (racine du dépôt).
